Hackathon project by M. Vijay and M. Rakhi. AI-powered waste analysis and smart response platform.

## Status
Stage 1 (Project foundation) complete. Full README is written in Stage 12.

## Run locally

```bash
npm install
npm run dev
```
Open http://localhost:5173
